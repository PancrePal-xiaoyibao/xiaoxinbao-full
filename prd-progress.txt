## Codebase Patterns
- Keep Gewechat raw payload parsing inside the wechat adapter module; downstream code only consumes normalized messages.
- Group conversations default to `actual_user_id@@group_id` so one user does not pollute another user's context in the same room.
- Local verification must run against the mock LLM gateway; tests must not depend on real model credentials or a live WeChat service.
- P0 does not persist user conversation content to disk; only non-sensitive metadata may appear in logs or docs.
- Compose application services through `src/xiaoxinbao/bootstrap.py` so tests and FastAPI routes share the same dependency graph.
- The P0 Gewechat adapter only accepts text messages (`MsgType == 1`); unsupported, expired, self, and non-user messages must short-circuit before Agent Core.
